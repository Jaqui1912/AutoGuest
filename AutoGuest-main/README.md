
# AutoGuest - Sistema de Gestión de Taller

## Descripción

AutoGuest es una aplicación multiplataforma para la gestión integral de talleres automotrices. Permite administrar clientes, servicios, mecánicos e historial de reparaciones de forma eficiente.

## Características

- **Roles de usuario:** Cliente, Administrador, Mecánico
- **Gestión de base de datos:** Control completo de registros y operaciones
- **Interfaz intuitiva:** Diseño responsivo optimizado para múltiples dispositivos
- **Lógica de negocio:** Implementación completa del flujo operativo
- **Arquitectura modular:** Código limpio y fácilmente mantenible
